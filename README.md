
현재는 **고정 BPM·박자표·전체 오프셋 복원 로직을 Windows 오디오 작업 앱에 연결하는 첫 버전**을 구현했습니다. 앱은 멀티트랙 기본 편집, 곡 전체 또는 선택 구간 분석, 그리드 청취·수정, 저장과 내보내기를 제공합니다. 승인된 A 수정으로 프로젝트 공통 Tempo·Signature 트랙, 마디 룰러, 하단 Transport, 트랙별 Linear/Musical 시간 기준과 클릭 음량 조절을 추가했습니다. 0.3.0에서는 세로 볼륨 페이더, 한 줄 Transport, 커서 드래그와 재생 위치 동기화, 다음 이벤트까지 유지되는 템포·박자 동작을 반영했습니다. 승인된 B 수정인 0.4.0에서는 드롭 위치·선택 트랙을 반영하는 가져오기, 파일 순서 변경, 독립 트랙과 연결된 스템 가져오기, 트랙 추가·복제·삭제·순서 변경과 Undo/Redo를 제공합니다. 분석기는 기존 고정 조건 실험을 사용하며, 자동 가변 템포·변박 분석은 구현하지 않았습니다. 소유자의 전수 테스트 요청으로 실제 Windows 동작과 경계 조건을 점검하고 발견한 문제를 수정했습니다. 구체적인 검증 범위와 한계는 [앱 검사 기록](apps/daw/audit/README.md)에 있습니다. 이 검사는 A·B 수정 이전의 초기 버전 대상이며, 이후 수정의 실행 검증은 포함하지 않습니다.

0.4.2의 A·B 영역은 별도의 요청으로 설치된 Cubase Pro 15와 합성 음원을 사용해 조사했습니다. 이 조사와 이후 수정의 실행 검증은 구분합니다. 0.4.3 첫 수정 묶음에는 트랙 이름 편집과 선택 상태, 템포 점 드래그, 위치 단축키, 알림 배치, 가져오기 취소 설정을 반영했습니다. 하단 BPM은 커서부터 적용하며, 원본 예측 복원은 값 복원과 프로젝트 적용을 분리합니다. 이번 수정은 빌드·앱 파일 갱신까지만 진행합니다.

기존 개발은 `legacy/`에 보존했습니다. 이전 분석 구현·가중치·관측 캐시·평가 기준을 새 구현에 이어받지 않았습니다. 이전 결과는 실패 사례를 이해하는 자료이며, 재사용 대상으로 남긴 것은 확보한 표본과 그 출처입니다.

```text
apps/daw/                                Windows 앱·편집·재생·분석 연결·내보내기
experiments/metronome_reconstruction_v1/   현재 추정기·평가기·청취 페이지
tools/ntm_collection/                     표본 수집·원본 시계 준비·소유자 오프셋 검토 도구
samples/                                 확보한 표본·출처·승인 참조·실험 결과 (로컬)
legacy/                                  이전 개발의 역사 자료
```

Windows 앱의 사용·빌드 방법은 [앱 안내](apps/daw/README.md), 현재 분석기의 입력·출력은 [실험 사용 안내](experiments/metronome_reconstruction_v1/README.md), 표본 수집 도구는 [수집 안내](tools/ntm_collection/README.md)에 기록했습니다. 개발 중 확인은 프로젝트 루트의 `Start Joljak.cmd`를 Windows에서 실행하면 됩니다. 로컬 배포 패키지는 `dist/Joljak-win-x64/Joljak.exe`입니다. 음원·체크포인트·가상환경·앱 런타임·실험 산출물·개인 연구 문서는 Git에 포함하지 않습니다.

## 표본과 실험 범위

현재 표본은 정식 36개와 보조 2개입니다. 정식 표본은 완성 녹음 25개, 원곡 발췌 10개, 합성 녹음 1개이며, 보조 표본은 GuitarSet 클립과 합성 DAW Template 2입니다. 표본의 역할·원본 시계·승인 오프셋·참조 범위는 로컬 `samples/catalog.json`과 [표본 안내](samples/README.md)에 보존합니다. 수집·검토 대기 항목은 없습니다.

첫 고정 조건 실험은 이전에 제외하지 않은 **26개를 모두 같은 valid 집합**으로 사용합니다. 완성곡·발췌·합성·보조라는 출처는 유지하면서 평가 분모는 나누지 않습니다. 나머지 12개는 이번 실험 범위 밖입니다. 실패한 예측 때문에 표본을 추가로 제외하지 않습니다.

## 현재 입력 계약

- 출력은 곡 전체의 quarter BPM 하나, 박자표 하나, 음원 시작에 대한 마디 첫 박 오프셋 하나입니다. 별도의 anchor 객체나 원래 DAW의 마디 번호는 필요하지 않습니다.
- BPM 후보는 30–400 범위의 정수 및 분모 4 이하 기약분수입니다. 박자표 후보는 3/4·4/4입니다.
- 초기 탭은 음원에서 준비한 후보의 1/2·1·2배 같은 **박 단위 선택에만** 사용합니다. 같은 단위를 고르는 155·160·165 같은 값은 전체 예측에 동일한 영향을 줍니다.
- 탭 숫자를 정확한 BPM의 목표·초기값·탐색 중심·점수·오프셋으로 사용하지 않습니다. 음원 후보와 점수를 먼저 계산하고 탭은 정수 배율로 바꾼 뒤 숫자를 버립니다.
- **초기 time signature는 받지 않습니다.** 박자표와 마디 첫 박을 음원에서 추정합니다. 초기 탭을 곡 전체에 사용할 수 있는 것은 현재의 고정 BPM 가정 때문입니다.
- 승인 참조의 이벤트는 이미 음원 상대 좌표입니다. 오프셋을 다시 적용하거나 원본 시계에서 참조를 재생성하지 않습니다.

## 보존된 결과

공식 Beat This 1.1.0의 새 final0 체크포인트와 새 관측을 사용했습니다. 예측을 먼저 저장하고 승인 참조로 평가했습니다. 각 실행의 설정·소스 스냅샷·예측·템포 맵·측정 수치는 로컬 실험 폴더에 보존합니다.

| 조건 · 같은 26개 | 명목 BPM 일치 | 박자표 일치 | 박·마디 최대오차 모두 20ms 이내 | 모두 30ms 이내 |
| --- | ---: | ---: | ---: | ---: |
| [첫 자동 실험](samples/experiments/metronome_reconstruction_v1/20261005-first26-v1/report.html) | 19/26 | 26/26 | 18/26 | 19/26 |
| [초기 탭 단위 진단](samples/experiments/metronome_reconstruction_v1/20261005-tap26-v2/report.html) | 26/26 | 26/26 | 24/26 | 25/26 |

첫 자동 실험의 7개 BPM 오류는 1/2배 5개와 2배 2개였습니다. 탭 단위 진단은 실제 사용자 탭 대신 승인 참조 BPM으로 올바른 단위를 제공한 실험입니다. 기준·−5·+5 BPM 힌트는 26개 모두에서 정확한 BPM·박자표·오프셋·점수·진단까지 동일한 전체 예측을 냈습니다. 같은 후보 처리에서 힌트를 빼면 19/26 BPM 결과가 유지됩니다.

최신 진단의 일반 beat 최대오차는 25개가 20ms 이내이며, 가장 큰 San Quentin도 20.52ms입니다. 곡 처음부터 끝까지의 누적 박 위치 차이는 최대 약 0.45ms입니다. 소유자는 청취 후 현재의 약 20ms 고정 오프셋 차이를 실용적으로 허용했습니다. 이 판단은 위의 엄격한 측정 수치나 저장된 결과를 바꾸지 않습니다.

주요 잔여 문제는 **Red Miso의 마디 첫 박 선택**입니다. 일반 beat 최대오차는 4.92ms이나 마디 첫 박은 약 449.90ms, 거의 한 박 차이입니다. 소유자는 복잡한 폴리리듬에서 4/4 해석이 어렵다고 설명했습니다. 이는 어려움을 이해하는 맥락이며 원인이 독립적으로 증명된 것은 아닙니다. Red Miso도 26개 분모에 그대로 남습니다.

이 수치는 알려진 표본의 기존 승인 참조와 비교한 결과입니다. 올바른 단위를 제공받은 조건의 성능이며, 실제 탭 정확도·미지곡 일반화·독립적인 원제작 클릭 정확도를 측정한 결과는 아닙니다.

## 결과 청취

최신 탭 실험에서 박·마디 최대오차 중 큰 값이 큰 순서로 **Red Miso, San Quentin, Equilibrium, DAW Template 2, The Gates**를 선정했습니다. 예측/기존 참조 클릭 전환, 원음·클릭 음량 조절, 마디 첫 박 강조, 구간 이동, 12초 반복을 지원합니다. The Gates의 참조가 없는 끝부분에서는 참조 클릭을 확장하지 않습니다.

```bash
python3 -m experiments.metronome_reconstruction_v1.serve_listening \
  --root samples/experiments/metronome_reconstruction_v1/20261005-tap26-v2/listening-bottom5 \
  --port 8997
```

페이지는 `http://localhost:8997/`에서 열 수 있습니다. 원격 환경에서는 8997 포트를 전달합니다. 서버는 지정된 5곡과 페이지 파일만 제공하며, 브라우저에서 음원과 클릭을 같은 재생 시계로 재생합니다. 재생 조작으로 저장된 예측·참조·원음이 수정되지 않습니다.

기존 26곡 실험과 승인 참조는 그대로 보존합니다. 앱 통합 검사는 별도 로컬 테스트 자료를 사용하며 새 정확도 벤치마크로 집계하지 않습니다. 이후 모델 실험·검증·Git 작업은 각 요청의 범위에 따릅니다.
