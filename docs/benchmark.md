# 13곡 공통 분석 경로의 개발 기준선

기준일: **2026-09-27**. 모든 곡에 같은 선택 규칙을 적용한 실험 결과이며, **13곡 중 10곡**이 필요한 모든 조건을 통과했습니다. 이미 관찰한 곡에서 규칙을 개발한 결과이므로 미관측곡 성공률을 추정하지 않습니다. 제품 기본 분석기로 채택한 상태도 아닙니다.

기계 판독용 [집계 JSON](benchmarks/primary13.json)은 점수·오탐·미탐·원본 결과 해시를 포함합니다. 원본 음원, 제작 MIDI·프로젝트, 승인 지도와 전체 예측 사건은 배포하지 않습니다.

## 평가 조건

| 항목 | 조건 |
| --- | --- |
| BPM 시간 정확도 | 참조 지원 시간 중 4분음표 BPM 오차 ±1 이내의 비율 |
| 검수 박자 | 시작·끝이 ±70ms 안에서 대응하는 마디의 승인된 박자 관계; 미대응 참조 마디도 분모에 포함 |
| 박 / 마디 시작 | ±70ms에서 일대일 대응한 F1 |
| 템포 변경 | ±500ms와 변경 전후 BPM ±0.1의 일대일 대응 |
| 박자 변경 | ±500ms와 변경 표기의 일대일 대응 |

여섯 항목을 **각각 90% 이상** 만족해야 한 곡을 통과로 셉니다. 추가 사건은 F1에서 감점하고, 참조에 변경이 없으면 거짓 변경 하나라도 해당 변경 항목을 실패시킵니다. 일정한 참조의 변경 점수 100%는 실제 변경을 찾았다는 의미가 아닙니다.

Sleeping With Sirens에는 음원 전에 시작한 마디의 표기를 제거해도 **음원 안의 전체 마디 시각이 동일한 경우**에 한정한 검수 규칙을 적용했습니다. 다른 추가 변경은 계속 감점합니다.

Walker는 고정 격자 [0.64675, 270.64675)초와 자유 엔딩 [270.64675, 299.064)초를 구분합니다. 자유 엔딩에 박·마디 클릭이 없어야 하며, 격자 종료 오차도 500ms 이내여야 합니다. 나머지 12곡은 전곡 지도입니다. 참조 검수는 독립적인 원본 클릭의 밀리초 정밀도 인증과 구분합니다.

## 대표적인 개선과 적용 범위

**State Shirt:** 기존 공통 부분은 일정한 약 109.71 BPM을 선택하여 네 템포 변경을 모두 놓쳤습니다. 원시 Beat This의 박/마디 F1은 96.98/95.28%였지만 일정 격자 재구성 후 58.60/32.18%로 감소했습니다. 마디 간격 기반 분할을 추가한 현재 경로는 네 변경을 모두 찾고 박 510 TP/0 FP/0 FN, 마디 128 TP/0 FP/0 FN을 얻었습니다. 관측과 재구성의 실패를 분리해서 본 사례입니다.

**Walker:** 기존 192 quarter BPM/6/4 해석을 96 quarter BPM/6/8로 변경하고 자유 엔딩에서 격자를 중지했습니다. 종료 시각은 승인 경계보다 약 14.8ms 이르며 자유 엔딩의 추가 클릭은 없습니다. 전체 박은 432 TP/1 FP/0 FN, 마디는 144 TP/0 FP/0 FN입니다.

두 사례의 규칙은 실패를 관찰한 뒤 개발했습니다. 이 개선은 알려진 사례의 복구이며 독립 시험의 성공으로 세지 않습니다.

## 연구 과정

| 단계 | 결과와 판단 |
| --- | --- |
| 모델과 후처리 분리 비교 | 박 사건 점수만으로 BPM·박자 지도 복원 성능을 평가할 수 없음을 확인 |
| 참조 정렬과 평가 정비 | 완성 음원·실제 제작 지도 검수, 지원 범위와 오탐·미탐을 명시 |
| 첫 8곡 공동 추론 | 지도는 출력했지만 BPM 시간 정확도 14.87%, 원표기 박자 8.67%와 과도한 거짓 변경으로 실패 |
| 11곡 일정 격자 대조군 | 여섯 조건을 모두 통과한 곡 6/11 |
| 알려진 11곡의 구조 근거 결합 | Circle → Naysayer → Archspire → Nocturne를 순차 검토하여 원표기 기준 10/11 |
| 음원 시작 표기 검수 | 동일한 음원 내 마디를 갖는 SWS 대안을 인정한 별도 조건에서 11/11; 엄격 10/11도 보존 |
| 기존 공통 부분을 새 두 곡에 적용 | Walker·State Shirt 모두 실패(0/2). 전체 11/11 조립 경로는 임의 곡용 실행기가 아니었음 |
| 같은 실행 규칙으로 통합 | 마디 간격 분할로 9/13, 6/8·종료 판단을 추가하여 현재 10/13 |

11/11과 10/13은 표본 수와 실행 경로가 모두 다릅니다. 이전의 Nocturne·Naysayer·Archspire 분기는 알려진 곡에서 준비한 관측·구조 가설에 의존했고, 현재 공통 실행기는 그 곡별 선택을 포함하지 않습니다.

## 재현과 다음 비교

공개 테스트는 합성 입력으로 시간 변환, 후보 선택의 수용·보류, 클릭 렌더링과 평가 규칙을 확인합니다. 원래의 13곡 성적을 재실행하려면 배포되지 않은 정확한 음원·관측·참조가 필요합니다. 집계 JSON에 포함한 해시는 원본 성적과 구현을 식별하기 위한 값이며 파일을 대신하지 않습니다.

향후 결과는 이 기준선을 덮어쓰지 않고 별도 버전으로 비교합니다. 곡별 여섯 점수와 박·마디·변경의 오탐/미탐, 기존 통과곡의 회귀를 함께 제시합니다. 새 곡의 적용 결과는 개발 표본 성적과 분리해야 합니다. 네이티브 Windows 제품, 준비 작업 시간 단축과 실제 공연 환경의 출력 검증은 남아 있습니다.
