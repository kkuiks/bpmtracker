# Decoder review sources

The [2026-10-22 snapshot](20261022/README.md) makes the measured G21 FULL decoder,
post-comparison selection prototypes and evaluator logic available for source
inspection. It also contains aggregate results; it contains no audio, weights,
observation arrays, reference vectors or per-record prediction artifacts.

Start with [the current method and review questions](../../docs/RESEARCH_REVIEW.md).
The maintained variable entry remains [L2](../../algorithms/variable/baseline.py),
and the Windows application uses the fixed estimator.

This area holds versioned review copies, not active algorithm imports or a new
experiment queue. Frozen originals remain in their recorded local research runs.
